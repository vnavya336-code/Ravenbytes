# ScholarBridge Starter Project

## Run on Windows (VS Code terminal)

1. Open this folder in VS Code.

2. Create a virtual environment:

   py -m venv venv

3. Activate it:

   venv\Scripts\activate

4. Install packages:

   pip install -r requirements.txt

5. Start the website:

   python app.py

6. Open:

   http://127.0.0.1:5000

## Features included

- Student form for 10th passed students.
- Student form for 12th passed students.
- Engineering undergraduate students.
- Basic eligibility matching.
- Reasons for eligibility mismatches.
- Scheme application links.
- Application deadline field.
- Optional Google search integration.
- Optional Gemini AI assistant.

## Optional Google Search

Configure Google Programmable Search Engine.

Set:

GOOGLE_CSE_API_KEY

GOOGLE_CSE_ID

## Optional Gemini AI

Set:

GEMINI_API_KEY

GEMINI_MODEL

Never share API keys publicly or commit them to GitHub.

## Accuracy note

The starter catalogue is not a complete or officially verified list of every scholarship.

Verify current eligibility, deadlines, amounts and application links on official government websites.
